# SSY — Job Spec: Full-Stack Developer (Early-Mid)

> Source: official role overview PDF supplied by the candidate. Confidence: CONFIRMED.

## About the Role
A curious and ambitious Full-Stack Developer to join the Technology team and help build and evolve
the **Offshore Broking platform** and related initiatives. Works closely with experienced developers
and business stakeholders; exposure to modern web tech, **AI-assisted development practices**, and
complex business systems.

## What You'll Be Working On
- Designing, building, maintaining features across web applications
- Responsive, intuitive UIs using **React and TypeScript**
- Backend services and APIs using **Node.js**
- Working with **PostgreSQL / SQL Server** databases and data models
- Contributing to architecture and technical design discussions
- Supporting ongoing development of the Offshore Broking platform
- Collaborating to deliver high-quality software
- **Exploring and adopting AI-powered development tools** to improve productivity and workflows

## Core Technical Skills — Essential
- Degree in CS, Software Engineering, or related
- Experience with: **React · TypeScript · Node.js · PostgreSQL**
- Software-engineering fundamentals: OOP · data structures & algorithms · RESTful API design · Git

## Nice to Have
Python · C# · Docker / Containerisation · **Next.js** · GraphQL · Cloud (AWS, Azure, or GCP) ·
Automated testing frameworks · CI/CD pipelines

## What We're Looking For
### Growth Mindset
- Eager to learn new technologies and frameworks
- Comfortable working across different parts of the stack
- Adaptable and willing to pick up new programming languages when required

### AI-First Thinking
> "We actively embrace AI-assisted development tools as part of our engineering workflow. We're
> looking for developers excited about leveraging AI to accelerate delivery while maintaining strong
> engineering judgement."
- Using AI tools to improve productivity and reduce repetitive work
- **Verifying and testing AI-generated code rather than blindly accepting outputs**
- Applying critical thinking and engineering principles to ensure quality solutions

### Collaboration
- Strong communication skills
- Comfortable working closely with developers, product stakeholders, and business users
- Open to feedback and continuous improvement
- Enjoys solving problems as part of a collaborative team
